تحديث قائمة حسابي والهوية البصرية - YNOVA STORE

- تحويل أقسام حسابي إلى أزرار قابلة للفتح والإغلاق (أكورديون)، مغلقة افتراضياً:
  رصيد المحفظة، نقاط الولاء، دعوة الأصدقاء، إثبات متابعة الصفحات،
  المعلومات الشخصية، توثيق الحساب، مشتريات متجر الحسابات.
- أقسام طلب التاجر، طلب API، تغيير كلمة المرور، وقفل الموقع بقيت قابلة للفتح والإغلاق.
- تحديث الواجهة إلى ألوان فاتحة واضحة: خلفية رمادية فاتحة، بطاقات بيضاء،
  نصوص داكنة، أزرق واضح للأزرار، وتباين محسّن.
- جعل الوضع الفاتح هو الافتراضي باستخدام مفتاح تفضيل جديد حتى لا تبقى
  تفضيلات الوضع الداكن القديمة مفروضة على الزوار.
- إضافة انتقالات قصيرة وسلسة مع احترام إعداد تقليل الحركة في الجهاز.

لم تُغيّر مسارات النماذج أو أسماء الحقول أو منطق قاعدة البيانات في هذا التحديث.
تم اجتياز فحص صياغة Python وفحص قوالب Jinja2 الثلاثين.
لم يتم إجراء اختبار تشغيل كامل على خادم الإنتاج؛ احتفظ بنسخة احتياطية قبل النشر.
