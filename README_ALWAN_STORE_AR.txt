ربط NOVA STORE مع 3lwan Store API
==================================

تمت إضافة مزوّد باسم 3lwan Store API إلى لوحة الإدارة مع الإبقاء على Syria Market وواجهات SMM التقليدية.

الإعداد من لوحة الإدارة:
1) افتح إعدادات مزوّدي SMM API.
2) اختر 3lwan Store API.
3) اسم المزوّد: علوان ستور (أو أي اسم تفضله).
4) عنوان API الافتراضي: https://3lwan-store.com
5) ضع API Token من صفحة إعدادات API في علوان ستور داخل خانة المفتاح الفعلي.
6) احفظ المزوّد ثم اضغط «اختبار API / الرصيد».
7) اضغط «تحديث الخدمات من السيرفر» لاستيراد المنتجات.
8) اربط معرّف المنتج المستورد بخدمة من NOVA STORE، ثم اختر مزوّد علوان ستور.

المسارات المنفذة وفق توثيق 3lwan Store:
- GET /client/api/profile/
- GET /client/api/products/
- GET /client/api/content/{category_id}/ (لجلب محتوى تصنيف)
- GET أو POST /client/api/newOrder/{product_id}/params/ مع qty و playerId و order_uuid بصيغة UUIDv4؛ يعتمد الموقع POST مع JSON كما في مثال التوثيق.
- GET /client/api/check/?orders=[order_id]؛ يرسل الموقع قائمة JSON صحيحة داخل orders.

المصادقة تتم عبر ترويسة api-token، والتوكن يبقى في الخادم ومخزناً مشفراً.

ملاحظات مهمة:
- لم يتم تنفيذ طلب شراء حقيقي أثناء تعديل الملفات؛ اختبار الاتصال وجلب المنتجات يتطلبان توكن صالحاً على استضافتك.
- يجب التأكد من أن عنوان IP الخاص باستضافتك مسموح ضمن إعدادات IP Whitelist لدى علوان ستور، إذا كانت الحماية مفعّلة.
- المنتجات التي تتطلب بيانات إضافية غير playerId تحتاج توسيع نموذج بيانات الخدمة لتمرير حقولها الصحيحة. الربط الحالي يرسل playerId من حقل الرابط/الآيدي الموجود في الخدمة.
- سعر المنتج المستورد هو سعر المزوّد كما يرجعه API؛ راجع سعر البيع الذي تحدده في NOVA STORE قبل إتاحة المنتج للزبائن.

ملاحظات مطابقة لصور التوثيق المرسلة:
- المصادقة عبر Header باسم api-token.
- الأكواد 120 و121 و122 و123 و130 تُعرض برسائل مفهومة لاكتشاف مشكلة التوكن أو صلاحية API أو IP أو الصيانة.
- يجب إدخال Base URL فقط (مثال: https://3lwan-store.com)، وليس رابط صفحة /api-docs.
