أوج ميديا - نسخة Flask جاهزة للتشغيل

المحتويات:
- app.py: تطبيق Flask جديد مع قاعدة بيانات SQLite تنشأ تلقائياً.
- templates/: صفحات الموقع العربية، القائمة الجانبية، الشريط السفلي، والبوت العائم.
- requirements.txt و Procfile.

التشغيل على Windows:
1) فك ضغط الملف.
2) افتح Terminal داخل مجلد المشروع.
3) أنشئ بيئة افتراضية (اختياري لكن موصى به): python -m venv .venv
4) فعّلها: .venv\Scripts\activate
5) ثبّت المكتبات: pip install -r requirements.txt
6) شغّل الموقع: python app.py
7) افتح http://127.0.0.1:5000

بيانات المدير الافتراضية:
اسم المستخدم: admin
كلمة المرور: ChangeMe123!
غيّر كلمة المرور قبل نشر الموقع على الإنترنت. يمكنك ضبط OWJ_ADMIN_USER و OWJ_ADMIN_PASSWORD كمتغيرات بيئة.

ملاحظات مهمة:
- هذه نسخة جديدة نظيفة؛ لم يتم نقل بيانات قاعدة البيانات القديمة، بناءً على طلبك.
- قاعدة البيانات owj_media.db تنشأ تلقائياً عند تشغيل التطبيق.
- البوت الحالي مساعد تجريبي بقواعد بسيطة، وليس نموذج ذكاء اصطناعي متصلاً بخدمة خارجية.
- قبل النشر: غيّر SECRET_KEY، واضبط كلمة مرور المدير، واستخدم HTTPS، واختبر تدفقات الدفع والطلبات.
- الأسعار وطرق الدفع والخدمات التجريبية يجب تعديلها من لوحة الإدارة قبل استقبال طلبات حقيقية.

تعديل v20: الأقسام والخدمات ثلاث بطاقات في كل صف، صور/أيقونات بمقاس 60×60 بكسل تقريبًا، والبطاقات مربعة مع حد أدنى للارتفاع.


إضافات الإصدار v32:
- قائمة الثلاثة خطوط تتضمن تبديل المظهر بين الليلي والنهاري، ويحفظ الاختيار في المتصفح.
- لوحة الإدارة تحتوي على إعداد مزوّد SMM: الاسم، رابط API، ومفتاح API، ثم اختيار المزوّد ورقم الخدمة عند إضافة خدمة تلقائية.
- إرسال الطلبات التلقائية متوافق مع صيغة SMM الشائعة (POST: key/action=add/service/link/quantity). تأكد أن مزوّدك يدعم هذه الصيغة وأن رابط API صحيح قبل تفعيل الخدمات.
- مفاتيح API حساسة؛ لا تشاركها ولا تضعها في ملفات عامة.


النسخ الاحتياطي الكامل (CSV)
----------------------------
- من لوحة الإدارة اضغط «تنزيل نسخة احتياطية كاملة (CSV)».
- يتضمن الملف سجلات جميع جداول قاعدة البيانات الحالية، بما فيها الحسابات وكلمات المرور المشفرة والأرصدة والطلبات والأقسام والخدمات ومزوّدي API والوكلاء وطرق الدفع وطلبات الشحن والشكاوى ورسائل الدعم.
- لاستعادة نسخة، ارفع الملف نفسه من لوحة الإدارة. الاستعادة تستبدل بيانات قاعدة البيانات الحالية بالكامل بمحتوى النسخة؛ خذ نسخة حديثة قبل الاستعادة.
- هذا ملف قاعدة بيانات CSV ولا يحتوي بايتات الصور المرفوعة إلى مجلد static/uploads. احتفظ بنسخة منفصلة من مجلد static/uploads إذا كنت تستخدم صوراً رفعتها بنفسك.
- ملفات CSV القديمة التي كانت تحفظ بعض حقول الحسابات فقط غير مدعومة كنسخة كاملة؛ نزّل نسخة جديدة بعد نشر هذا الإصدار.

تحديث v45:
