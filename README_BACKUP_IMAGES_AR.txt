تحديث النسخ الاحتياطي للصور - NOVA STORE

- بقيت أزرار النسخ الاحتياطي والاستعادة في لوحة الإدارة وبنفس أماكنها وتصميمها.
- زر تنزيل النسخة الاحتياطية ينشئ الآن ملف ZIP واحداً يحتوي قاعدة البيانات كاملة داخل backup.csv وجميع ملفات مجلد static، بما فيها صور المنتجات والأقسام والبنرات والملفات المرفوعة.
- يتم حفظ المسارات كما هي؛ لذلك تبقى روابط /static/uploads/... المسجلة في قاعدة البيانات متطابقة مع الملفات بعد الاستعادة.
- الاستعادة تقبل ZIP الجديد، وتبقي دعم CSV القديم. ملفات CSV القديمة لا تحتوي الصور، لذلك تستعيد البيانات فقط.
- قبل الاستعادة يتم فحص سلامة ZIP وبصمات SHA-256 ومسارات الملفات، ثم تجهيز الملفات قبل اعتماد التغييرات.
- لا يتم استخراج أي ملف خارج مجلد static.

مهم: سيحتوي ZIP على الملفات الموجودة فعلياً داخل مجلد static على الخادم وقت تنزيل النسخة. إذا كانت صور قديمة قد حُذفت مسبقاً من Render ولم تعد موجودة في static/uploads، فلن يمكن تضمينها في النسخة الجديدة.
