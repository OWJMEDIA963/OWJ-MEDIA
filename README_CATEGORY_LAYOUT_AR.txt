تحديث إدارة الأقسام - Y-N Store

تمت إضافة ما يلي:
1) رفع صورة عند إنشاء قسم رئيسي أو إدخال رابط الصورة.
2) إمكانية تعديل اسم وصورة كل قسم رئيسي أو فرعي من لوحة الإدارة.
3) إمكانية حذف صورة القسم أو استبدالها برفع صورة جديدة أو رابط جديد.
4) التحكم بترتيب ظهور الأقسام الرئيسية والفرعية عبر حقل «رقم الترتيب»؛ الرقم الأصغر يظهر أولاً.
5) إضافة ترحيل آمن لقاعدة البيانات لإضافة عمود sort_order إلى جدول category دون حذف بيانات الأقسام الحالية.

طريقة الاستخدام:
- ارفع ملفات المشروع إلى GitHub وانتظر اكتمال النشر على Render.
- افتح لوحة الإدارة.
- عند إنشاء قسم رئيسي، يمكنك رفع صورته مباشرة.
- في «إدارة صور وترتيب الأقسام»، عدّل بيانات القسم ثم اضغط «حفظ».
- لتغيير الترتيب، ضع رقماً أصغر للقسم الذي تريد عرضه قبل غيره. تنطبق هذه الأرقام بشكل مستقل على الأقسام الرئيسية وعلى الأقسام الفرعية داخل كل قسم رئيسي.
