تحديث YNOVA STORE: صلاحيات الموظف وأسعار التجار

1) من لوحة الإدارة، استخدم قسم «إنشاء حساب موظف بصلاحيات محدودة» لإنشاء حساب باسم مستخدم وكلمة مرور جديدة.
2) الموظف يستطيع الرد على تذاكر الدعم، عرض الطلبات، قبول/رفض طلبات التاجر، وقبول/رفض طلبات توثيق الحسابات فقط.
3) أزيلت أداة تحويل الرصيد من لوحة الموظف. لا يملك الموظف صلاحيات لوحة الإدارة لإدارة الأموال أو المنتجات أو الأسعار أو API أو إعدادات الموقع.
4) عند إضافة أو تعديل منتج، أدخل «سعر العامة» و«سعر التاجر». ترك سعر التاجر على 0 يعني استخدام سعر العامة.
5) حساب التاجر المعتمد يرى سعر العامة مشطوباً والسعر الخاص غير مشطوب. كما يُحسب سعر الطلب الفعلي بالسعر الخاص للتاجر على الموقع وطلبات API للحسابات المعتمدة.
6) أضيف ترحيل آمن يضيف عمود merchant_price لقواعد البيانات الحالية دون حذف البيانات الموجودة.

ملاحظات النشر:
- ارفع ملفات المشروع كاملة إلى GitHub ثم أعد النشر على Render.
- جرّب إنشاء حساب موظف جديد وتأكد من رفض الوصول إلى /admin بحساب الموظف.
- جرّب منتجاً تجريبياً بسعر عامة مختلف عن سعر التاجر، ثم اختبر العرض والطلب من حساب تاجر معتمد ومن حساب عادي.
- احتفظ بنسخة احتياطية من قاعدة البيانات قبل النشر.
