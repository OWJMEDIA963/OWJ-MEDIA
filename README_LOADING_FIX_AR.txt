إصلاح شاشة التحميل - Y-N Store

- إصلاح خطأ Jinja في CSS داخل templates/base.html الناتج عن وجود {# داخل قاعدة @media.
- إظهار شاشة تحميل تحمل علامة Y-N عند التنقل بين صفحات الموقع وإرسال النماذج وتحديث/مغادرة الصفحة.
- دعم طلبات fetch التي تبدأ بعد تفاعل مباشر من المستخدم، مع تجاهل طلبات التحديث الخلفية لتجنب ظهور شاشة التحميل بلا داعٍ.
- يمكن استدعاء window.ynShowLoading() و window.ynHideLoading() في عمليات رفع الملفات أو العمليات الطويلة المخصصة.

تم التحقق من:
- ترجمة app.py بنجاح.
- تحليل جميع قوالب Jinja وعددها 20 بنجاح.
- فحص صياغة JavaScript الخاص بشاشة التحميل باستخدام node --check.

لم يتم اختبار الاتصال بقاعدة بيانات أو بيئة Render الفعلية.
