إعداد مساعد YNOVA STORE:
- عند عدم وجود مفتاح AI، يستمر المساعد بالردود المحلية الموجودة.
- لتفعيل نموذج مجاني محدود عبر Groq Cloud، أضف متغير البيئة GROQ_API_KEY في الاستضافة.
- متغير اختياري: GROQ_MODEL=llama-3.1-8b-instant
- لا تضع المفتاح داخل الملفات أو مستودع GitHub، وقد تتغير حدود الاستخدام المجاني حسب مزود الخدمة.

طلبات التاجر:
- يرسل العميل الطلب من ملفه الشخصي.
- من لوحة الإدارة > طلبات التاجر و API تتم الموافقة أو الرفض وتحديد الدفعة الأسبوعية.
- الدفعة تُضاف عند أول زيارة بعد مرور 7 أيام من موعد الاستحقاق، مع إشعار.

API:
- موافقة الإدارة تصدر مفتاحًا خاصًا مشفرًا في قاعدة البيانات.
- المتاح حالياً: GET /api/v1/catalog و GET /api/v1/balance.
- إرسال الطلبات عبر API غير مفعّل في هذه النسخة.
- الدليل موجود على /api/docs للمستخدم الموافق على طلبه.
