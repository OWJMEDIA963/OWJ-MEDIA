NOVA STORE — تحديث الهوية والإضافات

تم تغيير الهوية المرئية إلى NOVA STORE مع الحفاظ على ملفات وخدمات Y-N Store القديمة دون حذف.

الإضافات:
1) بنرات إعلانية في الصفحة الرئيسية، متناوبة تلقائياً. يمكن للمدير إضافة صور PNG/JPG/WEBP/GIF (حتى 2MB) وتحديد رابط، ترتيب، وتفعيل/إيقاف أو حذف من /admin/banners.
2) عداد إشعارات غير مقروءة بجانب رصيد المحفظة في الشريط العلوي.
3) طلب حساب تاجر من الملف الشخصي. يراجع المدير الطلب من /admin/requests، ويوافق مع تحديد دفعة أسبوعية. الدفعة الأولى تضاف عند الموافقة، ثم تُضاف دفعة كل 7 أيام عند أول طلب للمستخدم للموقع بعد استحقاقها. أسعار الخدمات لم تتغير.
4) طلب API من الملف الشخصي. عند موافقة المدير يتم إصدار مفتاح API منفصل. يستطيع العميل عرض المفتاح من ملفه الشخصي، ويمكن للمدير تعطيل/إعادة تفعيل المفاتيح.

API:
- GET /api/v1/services
- POST /api/v1/orders
- Authentication header: Authorization: Bearer YOUR_API_KEY
- POST JSON: {"service_id": 123, "link": "https://...", "quantity": 1000}
- quantity غير مطلوب للخدمات ذات السعر الثابت/اليدوية.
- المفتاح مستقل لكل حساب؛ يتم حفظ بصمته للتحقق وتخزين نسخة مشفرة لعرضها داخل الملف الشخصي.

ملاحظات:
- صور البنرات تحفظ كـ data URI في قاعدة البيانات لضمان عدم فقدانها مع إعادة تشغيل الاستضافة.
- كل الجداول الجديدة تُضاف عبر db.create_all() عند بدء التطبيق. لا يتم حذف أو استبدال بيانات الجداول القديمة.
- الدفعات الأسبوعية تُنفذ عند زيارة التاجر للموقع بعد مرور 7 أيام؛ ليست مهمة مجدولة مستقلة على خادم خارجي.
- اختبارات التشغيل الكامل تتطلب تثبيت المكتبات الواردة في requirements.txt وإعداد متغيرات بيئة الموقع.
