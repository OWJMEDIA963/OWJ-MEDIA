تحديث مزامنة حالة الطلبات مع API

- عند إنشاء طلب تلقائي عبر SMM، يحفظ الموقع رقم الطلب الذي يرجعه مزوّد API.
- عند فتح صفحة «طلباتي» أو أثناء بقائها مفتوحة، يستعلم الموقع من API نفسه باستخدام action=status و order=رقم_طلب_المزوّد.
- يحوّل الحالات المعروفة إلى العربية ويعرضها للزبون، وينشئ إشعاراً داخل الموقع عند تغير الحالة.
- تمت إضافة ترحيل آمن يضيف الحقل provider_order_id إلى قاعدة البيانات الحالية دون حذف بيانات.

مهم: يجب أن يكون مزوّد API متوافقاً مع نمط SMM الشائع (action=status, order=...) وأن يُرجع قيمة status. الطلبات اليدوية لا تتحدث من API وتظل حالتها بيد الإدارة. الإشعارات الفورية إلى الهاتف تحتاج إعداد VAPID كما في إعدادات المشروع؛ وإلا يظهر إشعار داخل الموقع.
