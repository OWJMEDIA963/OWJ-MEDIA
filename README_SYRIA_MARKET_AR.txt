ربط NOVA STORE مع Syria Market
================================

تم إعداد الربط باستخدام REST API الرسمي مع الإبقاء على مزوّدي SMM/PerfectPanel التقليديين دون تغيير.

قبل التفعيل في سوريا ماركت:
1) عطّل خيار «إلزام توقيع HMAC» كما أكدت أنك فعلت.
2) اجعل سياسة الوصول «السماح لجميع العناوين» أو أضف IP خادم الاستضافة إذا اخترت العناوين المحددة.
3) أنشئ/استخدم مفتاح REST API الخاص بالمتجر (تظهر بدايته sst_ في صفحة بيانات الربط). لا تستخدم مفتاح PerfectPanel الذي يبدأ بـ spk_.

خطوات التفعيل في NOVA STORE:
1) افتح لوحة الإدارة > إعدادات مزوّدي SMM API.
2) اختر Syria Market REST API.
3) أدخل رابط API: https://api.syrimarket.com/client/api/v1
4) أدخل REST API Token في خانة المفتاح الفعلي ثم احفظ.
5) اضغط «اختبار API / الرصيد».
6) عند نجاح الاتصال اضغط «تحديث الخدمات من السيرفر».
7) اربط معرّف المنتج المستورد بخدمة NOVA STORE من نموذج إضافة/تعديل الخدمة.

المسارات المستخدمة:
- GET /profile
- GET /catalog/products
- GET /catalog/tree كمسار احتياطي للكتالوج
- POST /orders
- GET /orders/{order_id}

المصادقة: Authorization: Bearer <REST_API_TOKEN>.
طلبات POST تتضمن Idempotency-Key UUIDv4 جديداً. لم يتم إرسال HMAC لأن خيار إلزامه معطّل في حساب سوريا ماركت.

تنبيه تشغيلي:
- خطأ 401 يعني غالباً أن المفتاح غير صحيح/ملغى أو أنك أدخلت مفتاح spk_ الخاص بـ PerfectPanel بدلاً من مفتاح REST API.
- لا تضع المفتاح في HTML أو JavaScript ولا ترسله في المحادثة. أدخله من لوحة الإدارة فقط.
- يجب أن تكون بيانات params الخاصة بكل منتج مطابقة لـ required_params في كتالوج سوريا ماركت؛ الحقول تختلف من منتج لآخر.
- لا يمكن تأكيد الاتصال الفعلي أو إرسال طلب حقيقي دون إدخال مفتاح صالح في إعدادات استضافتك.
