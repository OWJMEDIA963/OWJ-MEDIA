ربط YNOVA STORE مع Syria Market
================================

تمت إضافة دعم بروتوكول Syria Market REST API مع الإبقاء على مزوّدي SMM/PerfectPanel التقليديين دون تغيير.

خطوات التفعيل بعد رفع الملفات:
1) افتح لوحة الإدارة > إعدادات مزوّدي SMM API.
2) اختر Syria Market REST API.
3) أدخل API Token الصادر من حساب سوريا ماركت في خانة المفتاح الفعلي.
4) اترك عنوان API الافتراضي كما هو:
   https://api.syrimarket.com/client/api/v1
5) احفظ المزوّد ثم اضغط «اختبار API / الرصيد».
6) اضغط «تحديث الخدمات من السيرفر» لاستيراد المنتجات.
7) اربط معرّف المنتج المستورد بخدمة YNOVA STORE من نموذج إضافة/تعديل الخدمة، واختر المزوّد الجديد.

المسارات المستخدمة حسب صور توثيق سوريا ماركت:
- GET /profile
- GET /catalog/products (مع fallback إلى /catalog/tree)
- POST /orders
- GET /orders/{order_id}

إنشاء الطلب يرسل product_id و qty و params.playerId، ويضيف Idempotency-Key فريداً.

مهم:
- لا يمكن اختبار الربط الفعلي أو تنفيذ طلب حقيقي دون API Token صالح ومسموح لحسابك.
- واجهة التوثيق المصورة تعرض مثال params.playerId فقط. إذا كان المنتج يحتاج أسماء حقول أخرى، يجب مطابقة الحقول مع مخطط المنتج في توثيق سوريا ماركت قبل تفعيل ذلك المنتج للبيع.
- لا تضع API Token في ملفات HTML أو JavaScript؛ أدخله من لوحة الإدارة فقط.
- يجب الحفاظ على SECRET_KEY الحالي في إعدادات الاستضافة حتى تبقى المفاتيح المشفرة قابلة للقراءة.
