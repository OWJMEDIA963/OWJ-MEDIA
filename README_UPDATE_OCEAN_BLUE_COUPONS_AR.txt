تحديث YNOVA STORE – Ocean Blue + التحقق من أكواد الخصم
======================================================

التعديلات المنفذة
-----------------
1) تنظيم روابط القائمة الجانبية داخل أزرار موحدة، مع أحجام ثابتة للأيقونات ومساحات اللمس، وتأثير Hover ودعم عرض الهاتف. أُبقيت الروابط وشروط ظهور روابط الإدارة كما كانت.
2) إبراز قسم رمز الدعوة في صفحة الحساب ببطاقة مستقلة، مع إبقاء زر نسخ الرمز ونسخ رابط الدعوة.
3) إضافة التحقق من كوبون الخصم داخل نافذة الطلب عبر POST إلى /api/coupons/validate، باستخدام جدول Coupon الحالي وقواعد التفعيل والانتهاء والحد الأقصى للاستخدامات.
4) عرض السعر الأصلي والخصم والسعر النهائي، وإعادة التحقق تلقائياً عند تغيير الكمية.
5) عند إرسال الطلب، يعاد التحقق من الكوبون وحساب السعر على السيرفر من سعر الخدمة وكمية الطلب. لا يستقبل السيرفر سعراً أو نسبة خصم من المتصفح، ولا يتم تطبيق الخصم مرتين.
6) الإبقاء على مسار الطلب الحالي وسجل CouponUse وعداد used_count، مع احترام سعر التاجر المميز والخدمات ذات السعر الثابت والخدمات ذات سعر الألف.

مسار التحقق
-----------
POST /api/coupons/validate
JSON: {"service_id": 1, "quantity": 1000, "code": "SAVE20"}
المسار يتطلب تسجيل الدخول ويعيد السعر الأصلي والخصم والنهائي أو سبب رفض الكود.

الاختبار
--------
- نجح فحص صياغة Python باستخدام py_compile.
- نجح فحص صياغة قوالب Jinja لجميع القوالب الـ30.
- نجح فحص صياغة JavaScript لنافذة الطلب باستخدام node --check.
- تعذر تشغيل اختبارات التكامل الفعلية لـFlask في بيئة البناء لأن حزم Flask وFlask-SQLAlchemy غير مثبتة، ولم تتوفر شبكة لتنزيل requirements.txt. لذلك يجب إجراء اختبار الطلبات الفعلي بعد تثبيت المتطلبات وتشغيل نسخة اختبار بقاعدة بيانات منفصلة قبل النشر.

ملاحظة التوافق
--------------
لم تتم إضافة جداول أو أعمدة جديدة ولم تُنفذ أي عملية حذف أو إعادة إنشاء لقاعدة بيانات المتجر.
