تحديث واجهة YNOVA STORE – تحسينات الحساب والألوان والمساعد
======================================================

التعديلات المضافة على نسخة Ocean Blue + Coupons:

1) قسم حسابي: ترتيب خدمات الحساب ضمن بطاقات/أزرار مستقلة، بعمودين على الشاشات الواسعة وعمود واحد على الهاتف، مع تأثير Hover وفتح تفاصيل البطاقة عند الضغط. لم تتغير روابط النماذج أو صلاحياتها أو مسارات الإرسال.
2) إجراءات الطلب: تمييز زر «تأكيد وإرسال الطلب» باللون الأصفر الذهبي لتمييز الإجراء الأساسي، مع بقاء التحقق من الكوبون ومسار الطلب كما هما.
3) الوضع الليلي والنهاري: تحسين زر التبديل، تحديث اسم الإجراء والأيقونة ولون شريط المتصفح، والإبقاء على حفظ اختيار المستخدم في localStorage.
4) الألوان المهمة: إبراز الإشعارات بعدّاد ذهبي، وتلوين رسائل النجاح والخطأ والتحذير والمعلومات بألوان واضحة.
5) المساعد الذكي: اعتماد هوية تركواز/بحري مستقلة عن ألوان المتجر البنفسجية السابقة، وتحسين نافذة المحادثة والرسائل والأزرار السريعة، مع دعم مظهر النهار والليل. لم يتغير API الخاص بالمساعد.
6) الكربون: لم يُعثر على طبقة أو نمط خلفية كربونية صريح في ملفات CSS/HTML ضمن هذه النسخة؛ التوصية البصرية هي اعتماد الخلفيات النظيفة وترك الكربون خارج الخلفيات الأساسية.

التحقق:
- نجح py_compile لملف app.py.
- نجح فحص صياغة قوالب Jinja لجميع القوالب الـ30.
- لم تتغير قاعدة البيانات أو مسارات الطلب أو الكوبونات.
- التغييرات الحالية واجهة وتصميم؛ لم يتم الادعاء بإجراء اختبار متصفح حي أو اختبار تكامل قاعدة بيانات.
