OWJ MEDIA V56 — نظام الأقسام الرئيسية والفرعية والمنتجات

الجديد في V56:
- دعم هيكل من 3 مستويات: قسم رئيسي ← قسم فرعي ← منتجات.
- مثال: خدمات سوشيال ميديا ← إنستغرام ← متابعين / لايكات / مشاهدات.
- مثال: شحن ألعاب ← PUBG Mobile ← باقات الشدات.
- عرض الأقسام الفرعية كبطاقات مستقلة بصور.
- لكل منتج صورة واسم ووصف وسعر وحقول طلب كما في النظام الحالي.
- من نموذج إضافة الخدمة في لوحة الأدمن اكتب اسم القسم الرئيسي واسم القسم الفرعي (اختياري)، ويمكن رفع صورة للقسم الفرعي أو وضع رابطها.
- ترك اسم القسم الفرعي فارغاً يحفظ المنتج مباشرة تحت القسم الرئيسي، وهذا يحافظ على طريقة الأقسام القديمة.
- أضيفت قاعدة البيانات بشكل إضافي وآمن دون حذف البيانات القديمة أو الطلبات أو الحسابات.

النشر:
1. فك الضغط.
2. ارفع محتويات مجلد owj_media_v56 إلى GitHub مع استبدال ملفات التطبيق.
3. تأكد من وجود متغيرات البيئة نفسها المستخدمة سابقاً على Render، خصوصاً DATABASE_URL و SECRET_KEY.
4. انتظر انتهاء النشر.
