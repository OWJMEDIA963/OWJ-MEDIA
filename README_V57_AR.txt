أوج ميديا V57 — إضافة لوحة ربط Serva API

تم البناء على ملفات V56 مع الإبقاء على ملفات المشروع وميزاته السابقة كما هي، وإضافة قسم جديد في لوحة الأدمن:

1) إعداد مفتاح التجربة srv_test_ وحفظه.
2) حقل اختياري للمفتاح الفعلي srv_live_ (اتركه فارغاً حالياً أثناء الاختبار).
3) زر «اختبار الاتصال بمفتاح التجربة» ويرسل عملية balance عبر POST إلى https://serva-s.com/api/v1.
4) زر «جلب الخدمات من Serva» ويرسل عملية services بمفتاح التجربة.
5) عرض أسماء الخدمات وأرقام Service ID والتصنيف والسعر وحدود الكمية.
6) زر «استخدام الرقم» يضع Service ID في حقل رقم الخدمة داخل نموذج إضافة المنتج.
7) مفاتيح Serva لا تُعرض بعد الحفظ، وتُخزّن مشفّرة في جدول مستقل serva_api_config.
8) إضافة cryptography إلى requirements.txt.

الأمان والتشغيل:
- ابدأ بمفتاح التجربة فقط. هذه الصفحة لا تنشئ طلبات شراء ولا تخصم رصيد Serva.
- لا تضع أي مفتاح API في GitHub أو في المحادثات أو في روابط URL.
- حافظ على قيمة SECRET_KEY الحالية في Render ولا تغيّرها؛ التشفير مشتق منها، وتغييرها يمنع فك تشفير المفاتيح المحفوظة.
- لا يلزم إضافة مفتاح Serva إلى Render يدوياً؛ أدخله من لوحة الأدمن. يجب أن يكون SECRET_KEY الموجود في Render ثابتاً وسرياً.
- Render سيقوم بتثبيت cryptography عند النشر من requirements.txt.

مهم:
هذه النسخة تضيف إدارة المفاتيح واختبار الاتصال وجلب قائمة الخدمات ونسخ Service ID إلى نموذج المنتج. لا تفعّل إرسال طلبات الزبائن الفعلية إلى Serva بعد؛ يلزم اختبار دورة الطلب والخصم ومتابعة الحالة بشكل منفصل قبل تشغيل الشراء المباشر، لتجنب الخصم المكرر أو الخاطئ.

النشر:
1) فك ضغط الملف.
2) ارفع محتويات مجلد owj_media_v55 إلى مستودع GitHub مع استبدال ملفات التطبيق.
3) لا تحذف قاعدة البيانات ولا تغيّر DATABASE_URL أو SECRET_KEY.
4) انتظر انتهاء نشر Render، ثم افتح لوحة الأدمن ← ربط Serva API.
5) أدخل مفتاح التجربة، احفظه، اضغط اختبار الاتصال، ثم جلب الخدمات.

الفحوص التي أُجريت قبل التسليم:
- python -m py_compile app.py
- check_templates.py: اجتازت القوالب العشرون فحص الصياغة.
- لم يُجرَ اختبار اتصال حي مع Serva أو اختبار نشر حي على Render في هذه البيئة.
