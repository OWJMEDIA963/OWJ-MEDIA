ميزات YNOVA STORE المضافة
=========================

1) لوحة الإحصائيات /admin/analytics:
   تعرض إجمالي الطلبات وطلبات اليوم والمكتملة والمعلقة وعدد العملاء وقيمة الطلبات المكتملة، إضافة إلى أكثر الخدمات طلباً وآخر التقييمات.
   قيمة الطلبات المكتملة إجمالي مبيعات وليست صافي ربح؛ تكلفة المزوّد غير متاحة دائماً في البيانات الحالية.

2) كوبونات الخصم:
   من لوحة الإدارة يمكن إنشاء كوبون بنسبة مئوية أو مبلغ ثابت، وتحديد سقف استخدام وتاريخ انتهاء، ثم تفعيله أو تعطيله.
   العميل يدخل الكود في نافذة الطلب. يتم احتساب الخصم قبل خصم رصيد المحفظة.

3) نقاط الولاء:
   يكسب العميل نقطة واحدة على الأقل عن كل طلب مدفوع ناجح، وتُضاف النقاط بعد قبول الطلب وحفظه.
   يمكن استبدال كل 70 نقطة بدولار واحد من صفحة الحساب الشخصي.

4) مراقبة مزوّدي API:
   أضيف قسم مركزي يعرض مزوّدي API وحالة تفعيلهم، مع زر لاختبار الاتصال والرصيد يدوياً.
   لا يجري فحصاً آلياً متكرراً حتى لا يستهلك رصيد المزوّد. سجل آخر نجاح/فشل الدائم غير مضاف بعد.

5) تقييم الخدمات:
   يستطيع العميل تقييم الطلب بعد تحوّل حالته إلى «مكتمل» مرة واحدة لكل طلب، مع تعليق اختياري.
   تظهر أحدث التقييمات في لوحة الإحصائيات.

6) مركز الإشعارات:
   أضيف إرسال إشعار عام لجميع الحسابات غير المحظورة من لوحة الإدارة، بالإضافة إلى إشعارات نقاط الولاء.
   مركز إشعارات المستخدم الموجود مسبقاً بقي كما هو.

قاعدة البيانات:
- تمت إضافة جداول coupon وcoupon_use وservice_review عبر db.create_all.
- تمت إضافة عمود loyalty_points بترحيل إضافي آمن لا يحذف بيانات المستخدمين.
- النسخ الاحتياطي الحالي يلتقط الجداول الجديدة تلقائياً لأنه يقرأ جميع نماذج SQLAlchemy.

ملاحظات تشغيل:
- شغّل التطبيق كالمعتاد مع متطلبات requirements.txt.
- احتفظ بقيمة SECRET_KEY ثابتة في بيئة الاستضافة.
- اختبر إنشاء كوبون وطلباً تجريبياً في بيئة اختبار قبل تفعيل العروض للعملاء.


تحديث معاينة كوبون الخصم:
- عند كتابة كود الخصم في نافذة الطلب، يتحقق الموقع منه مباشرة دون استهلاك الكوبون.
- يعرض السعر قبل الخصم، وقيمة الخصم، والسعر النهائي فوراً.
- يعاد التحقق من صلاحية الكوبون والسعر على الخادم عند إرسال الطلب؛ المعاينة لا تحجز الكوبون ولا تزيد عدد استخداماته.
