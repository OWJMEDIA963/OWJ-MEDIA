أوج ميديا - نسخة Flask جاهزة للتشغيل

المحتويات:
- app.py: تطبيق Flask جديد مع قاعدة بيانات SQLite تنشأ تلقائياً.
- templates/: صفحات الموقع العربية، القائمة الجانبية، الشريط السفلي، والبوت العائم.
- requirements.txt و Procfile.

التشغيل على Windows:
1) فك ضغط الملف.
2) افتح Terminal داخل مجلد المشروع.
3) أنشئ بيئة افتراضية (اختياري لكن موصى به): python -m venv .venv
4) فعّلها: .venv\Scripts\activate
5) ثبّت المكتبات: pip install -r requirements.txt
6) شغّل الموقع: python app.py
7) افتح http://127.0.0.1:5000

إنشاء حساب المدير الأول:
اضبط OWJ_ADMIN_USER و OWJ_ADMIN_PASSWORD في متغيرات البيئة قبل أول تشغيل، ويجب أن تكون كلمة المرور 8 أحرف على الأقل. لن يغيّر التطبيق كلمة مرور المدير عند كل إعادة تشغيل.

ملاحظات مهمة:
- هذه نسخة جديدة نظيفة؛ لم يتم نقل بيانات قاعدة البيانات القديمة، بناءً على طلبك.
- قاعدة البيانات owj_media.db تنشأ تلقائياً عند تشغيل التطبيق.
- البوت الحالي مساعد تجريبي بقواعد بسيطة، وليس نموذج ذكاء اصطناعي متصلاً بخدمة خارجية.
- قبل النشر: غيّر SECRET_KEY، واضبط كلمة مرور المدير، واستخدم HTTPS، واختبر تدفقات الدفع والطلبات.
- الأسعار وطرق الدفع والخدمات التجريبية يجب تعديلها من لوحة الإدارة قبل استقبال طلبات حقيقية.
