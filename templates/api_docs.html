واجهة API الخاصة بـ NOVA STORE

تربط موقعك بـ NOVA STORE: تعرض الخدمات، تتحقق من رصيد العميل، ترسل الطلبات وتخصم قيمتها من محفظته.

المصادقة

كل طلب يحتاج مفتاح API معتمد من الإدارة. أرسل المفتاح في الترويسة:

Authorization: Bearer YOUR_NOVA_API_KEY

لا تضع المفتاح في JavaScript أو تطبيق المتصفح. خزّنه في الخادم فقط.

1. قائمة الخدمات

GET /api/v1/catalog

curl -H "Authorization: Bearer YOUR_KEY" {{request.host_url}}api/v1/catalog

2. رصيد العميل

GET /api/v1/balance

curl -H "Authorization: Bearer YOUR_KEY" {{request.host_url}}api/v1/balance

3. إرسال طلب وخصم الرصيد

POST /api/v1/order · Content-Type: application/json

curl -X POST {{request.host_url}}api/v1/order \\
  -H "Authorization: Bearer YOUR_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"service_id": 12, "link": "https://example.com/user", "quantity": 1000}'

الخدمات ذات الكمية الثابتة لا تحتاج quantity. لا يُخصم الرصيد إذا كان غير كافٍ أو رفض المزوّد الطلب.

4. متابعة طلبات العميل

GET /api/v1/orders?limit=50

curl -H "Authorization: Bearer YOUR_KEY" "{{request.host_url}}api/v1/orders?limit=50"

ملاحظات مهمة

  • الأسعار والخصم تُحسب من إعدادات خدمات NOVA STORE، ولا يقبل الخادم سعرًا يرسله العميل.
  • الطلب يُسجل على حساب صاحب مفتاح API المعتمد فقط.
  • لا تعاود إرسال طلب POST تلقائياً عند انقطاع الاتصال؛ تحقق أولاً من قائمة الطلبات لتجنب تكرار الطلب.
  • كل الأسعار والرصيد بالدولار USD في استجابة API.
  • أرسل المفتاح في Authorization Bearer، ولا تشاركه مع أي عميل آخر.
